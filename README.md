# MoveTogether+ 🤝

### Share a mobility aid. Help someone move forward.

MoveTogether is a community-based mobility aid-sharing platform designed to connect people who need mobility aids with people willing to support them.

The project aims to encourage accessibility, independence, and community support through a simple and user-friendly website.

## 🌟 Features

- **Explore Mobility Needs:** Browse sample requests for wheelchairs, crutches, and walkers.
- **Search Functionality:** Search and filter mobility aid requests.
- **Give Support:** Register your interest in supporting someone.
- **Request an Aid:** Submit a sample mobility aid request.
- **Handover Records:** Record mobility aid handovers.
- **Contact Form:** Submit demo messages.
- **Login & Signup UI:** Interactive demonstration popups.
- **Responsive Design:** Works on desktop and mobile devices.

## 🛠️ Technologies Used

- HTML5 – Website structure
- CSS3 – Styling and responsive design
- JavaScript – Interactive functionality
- LocalStorage – Saving demo form entries in the browser

## ⚠️ Important Note

This is a college demonstration project. All mobility aid requests are fictional. Forms store information only in the user's browser using LocalStorage. No real requests, payments, accounts, or messages are processed.

## 🎯 Project Objective

To demonstrate how web technologies can be used to create a platform that promotes community participation, accessibility, and support for people who need mobility assistance.
